# 01 - Planning

Use `new-plan` for non-trivial work.

Mandatory outputs:
- objective and non-objectives
- work breakdown by atomic steps
- acceptance criteria per step
- validation harness per step
- dependencies and blockers
- risks/mitigations

Then use:
- `plan-to-issues` to create agent-ready issues
- `qa-issue-spec` to attach complete QA package

Planning is not complete without issue contract quality and dedupe preflight.
