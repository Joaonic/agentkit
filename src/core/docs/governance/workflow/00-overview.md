# 00 - Overview

## Objective

Guarantee predictable delivery quality from request to merge readiness.

## Hard Requirements

- explicit scope and non-scope
- issue-level acceptance criteria
- test-first discipline for behavior changes
- findings-first review
- command-level posttask evidence

## Anti-Patterns (Blocked)

- implementing from ambiguous requests
- merging without CI/result evidence
- claiming completion with failed checks hidden in summary
- keeping contradictory governance docs
