# Docs Audit

## Audit Scope

- `docs/governance/cursor`
- `docs/cursor` bridge docs (if present)
- `.cursor/rules`, `.cursor/skills`, `.cursor/agents`
- `AGENTS.md`

## Checklist

1. canonical source integrity
2. workflow-to-implementation sync
3. duplicate/conflicting normative guidance
4. stale/broken references
5. VCS terminology consistency by repository

## Output

- critical contradictions/blockers
- important cleanup items
- optional improvements
